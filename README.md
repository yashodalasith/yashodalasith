## Selected Projects

#### [GeoExplorer-Deoplyment](https://github.com/yashodalasith/GeoExplorer-Deoplyment) — live [demo](https://geo-explorer-deoplyment-frontwork.vercel.app/)
Country explorer built on the REST Countries API, with list, 2D map, and 3D globe views, search/filter, and saved favorites behind JWT auth. The only one of my projects with a full automated test suite — Vitest, React Testing Library, and mocked API tests.
`React` `Leaflet` `React Three Fiber` `Express` `MongoDB` `Vitest`

#### [Q-AnalyzerX](https://github.com/yashodalasith/Q-AnalyzerX)
A code-analysis engine that parses quantum and classical source (Qiskit, Q#, Cirq, OpenQASM) into an AST and uses ML to classify known algorithms — Grover's, Shor's, QFT, VQE — and estimate circuit depth and qubit count. An independent build of the code-analysis-engine component I designed for **Nexar**, a six-service team research platform that represented SLIIT at the National ICT Awards (NBQSA) 2026.
`Python` `FastAPI` `ANTLR4` `TensorFlow` `scikit-learn`

#### [LankaVoyage-AI](https://github.com/yashodalasith/LankaVoyage-AI)
A multi-agent system that generates personalized Sri Lanka travel itineraries, with separate agents for research, optimization, and personalization orchestrated via LangGraph, plus local LLM inference through Ollama. Includes automated tests and structured logging.
`Python` `LangGraph` `Ollama` `FastAPI` `pytest`

#### [ShotSense-AI](https://github.com/yashodalasith/ShotSense-AI)
A computer-vision pipeline for cricket batting analysis — extracts pose data from video, engineers features from it, and classifies shot type while scoring stance consistency.
`FastAPI` `Pose Estimation` `scikit-learn` `OpenCV`
